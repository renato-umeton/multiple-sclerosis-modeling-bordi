# stats

Trial statistics on relapse event tables: the annualised relapse rate with an
exact Poisson interval, a negative binomial interval and a patient level
bootstrap, the rate ratio between two arms by Poisson or negative binomial
regression with the follow up as an offset, the relapse free curve, and the
negative binomial sample size of Zhu and Lakkis.

Nothing here is specific to the double well. These are the statistics one would
report for any relapsing-remitting record, and they are what a simulated cohort
has to reproduce before the model is taken seriously.
