    datasets ¶

    The synthetic twin of the 2013 cohort, its provenance and the closing table.

    The clinical records of Bordi et al. 2013 were never released: section 14 of docs/paper_facts.md records that the article carries no data availability statement, no supplementary material and no deposited series. What this package ships instead is a synthetic twin, three files of 70 records generated by :func:msrelapse.cohort.generate from the numbers the article prints, in the three schemas of :mod:msrelapse.io. :func:provenance says so in full, and :func:load_synthetic_bordi2013 puts the first line of it on the frame it returns.

    The twin is not the cohort of the study and no clinical claim can be read off it. What it is for is the closing table of :func:reproduction_table, which takes a weekly record and measures on it, the way the paper measured its own, every aggregate the article reports: the two mean durations, the three ranges, the barrier ratio of equation (7), and the two qualitative claims the article makes without a test. A reader who obtains the real series from the corresponding authors can run the same function on it and read the same table.

    References

    I. Bordi, R. Umeton, V. A. G. Ricigliano, et al., "A mechanistic, stochastic model helps understand multiple sclerosis course and pathogenesis", International Journal of Genomics, 2013, doi 10.1155/2013/910321.

    SYNTHETIC_SEED module-attribute ¶

    SYNTHETIC_SEED: Final = 20130910

    Seed the shipped files were generated from.

    It opens with the year of the volume the article appeared in, which docs/paper_facts.md records, and closes with four arbitrary digits, so that the number is memorable. The article carries no issue date and none is claimed here.

    def load_synthetic_bordi2013(schema: Schema = "weekly") -> pd.DataFrame:
    """Read one of the three shipped files and validate it against its schema.

    Parameters
    ----------
    schema : {'weekly', 'durations', 'events'}, optional
        Which shape of the same 70 records to read.

    Returns
    -------
    pandas.DataFrame
        The records, with the columns of that schema in schema order. The frame
        carries the first line of :func:`provenance` in
        ``frame.attrs['provenance']``.

    Raises
    ------
    ValueError
        If `schema` is not one of the three names, or if the shipped file does
        not obey the schema it claims.

    Notes
    -----
    ``attrs`` is metadata that pandas propagates through some operations and
    drops in others: a ``groupby`` or a merge usually loses it, and a slice
    usually keeps it. Read it off the frame this returns rather than off one
    derived from it, and call :func:`provenance` for the full note, which is
    never attached to anything.

    Examples
    --------
    >>> frame = load_synthetic_bordi2013()
    >>> frame["patient_id"].nunique() == PAPER.n_patients.value
    True
    """
    name = _csv_name(schema)
    with resources.as_file(_data_file(name)) as path:
        if schema == "weekly":
            frame = read_weekly(path)
        elif schema == "durations":
            frame = read_durations(path)
        else:
            frame = read_events(path)
    frame.attrs["provenance"] = provenance().splitlines()[0]
    return frame

    def regenerate_synthetic_bordi2013(
    out_dir: str | Path | None = None,
    seed: int = SYNTHETIC_SEED,
) -> dict[str, Path]:
    """Generate the three shipped files again and write them out.

    The cohort is ``generate(bordi2013_spec("renewal"), rng=seed)``, which is
    exactly the call the shipped files came from, so running this with the
    default arguments into the data directory of the package rewrites those
    files with the same bytes.

    Parameters
    ----------
    out_dir : str or pathlib.Path, optional
        Directory to write into, created if it does not exist. The default is
        the data directory of the installed package, which is refused for any
        seed but :data:`SYNTHETIC_SEED`.
    seed : int, optional
        Seed of the cohort. The default is :data:`SYNTHETIC_SEED`.

    Returns
    -------
    dict of str to pathlib.Path
        The path written for each of the three schemas, keyed by schema name.

    Raises
    ------
    ValueError
        If `seed` is not :data:`SYNTHETIC_SEED` and no `out_dir` is named, since
        a cohort under another seed is not the shipped twin and overwriting the
        shipped files with it would leave three files that ``PROVENANCE.txt``,
        :data:`SYNTHETIC_SEED` and the closing table no longer describe. Or if
        the generated cohort holds no weekly record, which cannot happen for the
        spec of the paper and is checked so that a future change to that spec
        fails here rather than writing an empty file.

    Notes
    -----
    The default directory is found from the location of this module rather than
    through :mod:`importlib.resources`, which is how the files are read. The two
    agree for an ordinary installation, which is the only one a file can be
    written into at all: a package imported out of a zip archive or a wheel has
    nowhere to put the result, and a caller in that position has to name an
    `out_dir` of their own.
    """
    if out_dir is None and seed != SYNTHETIC_SEED:
        raise ValueError(
            f"seed {seed!r} is not {SYNTHETIC_SEED}, the seed of the shipped twin, so the "
            f"cohort it generates is not the twin the provenance note and the closing table "
            f"describe; give it an out_dir of its own rather than letting it overwrite the "
            f"three files in the data directory of the package"
        )
    cohort = generate(bordi2013_spec("renewal"), rng=seed)
    if cohort.weekly is None or cohort.durations is None:
        raise ValueError(
            "the cohort of bordi2013_spec produced no weekly record, so the durations file "
            "cannot be written; the spec has to keep weekly=True for the shipped twin"
        )
    directory = Path(__file__).parent / _DATA_DIRECTORY if out_dir is None else Path(out_dir)
    directory.mkdir(parents=True, exist_ok=True)
    frames: dict[Schema, pd.DataFrame] = {
        "weekly": cohort.weekly,
        "durations": cohort.durations,
        "events": cohort.events,
    }
    written: dict[str, Path] = {}
    for schema, frame in frames.items():
        path = directory / _csv_name(schema)
        write_csv(frame, path)
        written[schema] = path
    return written

    reproduction_table ¶

    reproduction_table(
    weekly: DataFrame, alpha: float | None = None
) -> DataFrame

    Measure on a weekly record every aggregate the article reports.

    Each row puts the number the article prints beside the number this record gives, the rule the two are compared under and whether the rule is met. Every printed number comes from :data:msrelapse._params.PAPER, and every mean is the naive one, over every recorded run of a state with no censoring correction, because that is how the paper computed its own.

    Parameters:

    Name Type Description Default
    weekly DataFrame

    A frame in the weekly schema of :mod:msrelapse.io. It is validated before use.

    		 required
    alpha float

    Significance level the three p value rows are judged at, the two goodness of fit rows and the periodicity row. The default of None uses 0.05.

    		 None

    Returns:

    Type Description
    DataFrame

    One row per reported quantity, with the columns quantity, paper, reproduced, tolerance and within_tolerance. A range is held as a tuple of two floats. paper is None where the article reports nothing, and tolerance and within_tolerance are None where no rule applies.

    Raises:

    Type Description
    ValueError

    If weekly does not obey the weekly schema, if it holds no run of one of the two states, or if alpha is not strictly between 0 and 1. Two rows carry a requirement of their own on top of that, and a short record meets both easily: the goodness of fit rows need at least two complete, uncensored durations of each state, and the periodicity row needs at least one patient whose periodogram the pooled test can read, which asks for eight weeks of follow up, three relapse onsets and onsets that do not fall in every other week. The table is a cohort measurement; a handful of records does not carry it.
    Notes

    The barrier ratio row is judged against what equation (7) gives for the two durations the article prints, which :func:msrelapse.model.barrier_ratio_from_durations recomputes, and not against the rounded ratio the article prints beside them. Its tolerance, _BARRIER_RATIO_TOLERANCE, is deliberately loose, because the ratio is built from two mean durations and inherits the error of both: on a cohort of the size of the study, one standard error of the two means already moves it by about 0.13, and the tolerances of the two mean rows above propagate to about 0.18. A bound as tight as 0.05 needs a cohort several times larger than the seventy records the article followed, whatever the pipeline does; the source of this module carries the measurement beside the constant.

    That row is the only barrier ratio row of the table, and the three worked examples of Section 3.4 are deliberately not rows of it. The ratios of patients 23, 32 and 53 are read off the durations the article prints for each of them and not off any record, so there is nothing in a weekly frame to put beside them: the twin holds no counterpart of those three patients, and a real series obtained from the corresponding authors would number its own. :func:msrelapse.cohort.paper_patients recomputes the three from the printed durations, one row per patient, which is where that comparison belongs.

    How often the whole table comes out True is worth knowing before reading one: not every time. Regenerating the twin under the sixty consecutive seeds from :data:SYNTHETIC_SEED and building this table on each of the sixty cohorts, every judged row is True on 27 of them. The five percent relapse mean row is the one that fails most often, on 24 of the 60, and the ten percent remission mean row on 8, the barrier ratio row on 7, the relapse range row on 6 and the remission goodness of fit row on 1; the two remaining range rows, the relapse goodness of fit row and the periodicity row are True on all sixty. A False row is therefore the sampling noise of seventy records rather than a fault of the pipeline that built them, and the source of this module carries the sweep beside each tolerance it belongs to. The shipped twin is the first cohort of that sweep, the one :data:SYNTHETIC_SEED names and the one the provenance note describes: on it the relapse mean lands 4.2 percent below the printed value and the remission mean 4.3 percent above it.

    Three rows are not comparisons with a printed number, because the article prints none: section 7 of docs/paper_facts.md records that it reports no fit, no test and no interval anywhere, and that its exponential and no-periodicity claims rest on the shape of two histograms. Their paper entry is therefore None, and they are read as follows.

    The two Kolmogorov-Smirnov rows are judged, at alpha, against the claim the article makes in prose: that the durations of each state carry no typical scale. The p value is the parametric bootstrap of :func:msrelapse.fit.test_memoryless, drawn from a generator seeded inside this module so that the table is the same table every time it is built, and a p value above alpha means the record is consistent with a memoryless duration rather than that it is one.

    The periodicity row is judged at alpha in the same way, against the article's other claim in prose: that the relapses carry no typical period. The p value is the pooled Fisher g test of :func:msrelapse.fit.test_periodicity, read on the relapse onsets of every patient rather than on the +1 and -1 state series, because the onsets of a memoryless record have the flat spectrum the g test compares against while the state series does not. A p value above alpha means the record leaves the claim of the article standing, not that no rhythm exists.

    That row says little about the shipped twin, and its own figures say how little: 29 of the 70 records carry fewer than three relapse onsets and are skipped, 28 of the 41 that are read give a per patient p value of exactly 1, the smallest of the 41 is 0.24, and the pooled value is 1.0. At about four onsets per record, that is what a test of almost no power returns rather than a measurement of the cohort; the Notes of :func:msrelapse.fit.test_periodicity carry the measured size at a handful of onsets. Putting the claim of the article at any risk needs records followed for longer, not a rule written more tightly.

    None of the three says more than a goodness of fit p value can. Failing to reject is not evidence of the null, and a cohort of seventy records is not a large sample; read the three rows as the record declining to contradict the article rather than as a confirmation of it.

    Examples:

    >>> table = reproduction_table(load_synthetic_bordi2013())
>>> table["quantity"].iloc[0]

    def reproduction_table(weekly: pd.DataFrame, alpha: float | None = None) -> pd.DataFrame:
    """Measure on a weekly record every aggregate the article reports.

    Each row puts the number the article prints beside the number this record
    gives, the rule the two are compared under and whether the rule is met.
    Every printed number comes from :data:`msrelapse._params.PAPER`, and every
    mean is the naive one, over every recorded run of a state with no censoring
    correction, because that is how the paper computed its own.

    Parameters
    ----------
    weekly : pandas.DataFrame
        A frame in the weekly schema of :mod:`msrelapse.io`. It is validated
        before use.
    alpha : float, optional
        Significance level the three p value rows are judged at, the two
        goodness of fit rows and the periodicity row. The default of None uses
        0.05.

    Returns
    -------
    pandas.DataFrame
        One row per reported quantity, with the columns ``quantity``,
        ``paper``, ``reproduced``, ``tolerance`` and ``within_tolerance``. A
        range is held as a tuple of two floats. ``paper`` is None where the
        article reports nothing, and ``tolerance`` and ``within_tolerance`` are
        None where no rule applies.

    Raises
    ------
    ValueError
        If `weekly` does not obey the weekly schema, if it holds no run of one
        of the two states, or if `alpha` is not strictly between 0 and 1. Two
        rows carry a requirement of their own on top of that, and a short record
        meets both easily: the goodness of fit rows need at least two complete,
        uncensored durations of each state, and the periodicity row needs at
        least one patient whose periodogram the pooled test can read, which asks
        for eight weeks of follow up, three relapse onsets and onsets that do
        not fall in every other week. The table is a cohort measurement; a
        handful of records does not carry it.

    durations the article prints, which

    against the rounded ratio the article prints beside them. Its tolerance,
    ``_BARRIER_RATIO_TOLERANCE``, is deliberately loose, because the ratio is

    patients 23, 32 and 53 are read off the durations the article prints for
    each of them and not off any record, so there is nothing in a weekly frame
    to put beside them: the twin holds no counterpart of those three patients,

    Examples
    --------
    >>> table = reproduction_table(load_synthetic_bordi2013())
    >>> table["quantity"].iloc[0]
    'mean relapse duration (weeks)'
    """
    level = _DEFAULT_ALPHA if alpha is None else alpha
    if not 0.0 < level < 1.0:
        raise ValueError(f"alpha must lie strictly between 0 and 1, got {alpha!r}")
    runs = weekly_to_durations(weekly)
    relapses = runs.loc[runs["state"] == _NO_HEALTH, "duration_w"]
    remissions = runs.loc[runs["state"] == _HEALTH, "duration_w"]
    if relapses.empty or remissions.empty:
        raise ValueError(
            f"the record holds {relapses.size} relapse run(s) and {remissions.size} remission "
            f"run(s), so the table has no mean duration to report for one of the two states"
        )
    phase = weekly.groupby("patient_id", sort=True).size()
    rows = [
        *_duration_rows(relapses, remissions),
        *_range_rows(relapses, remissions, phase),
        _barrier_ratio_row(runs),
        *_memoryless_rows(runs, level),
        _periodicity_row(weekly, level),
    ]
    # Column by column and as object, so that a column holding both a value and
    # a None keeps the None rather than turning it into a missing float, and so
    # that the two columns holding a pair of weeks can hold the pair.
    columns = zip(*rows, strict=True)
    return pd.DataFrame(
